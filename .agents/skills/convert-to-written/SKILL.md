# 书面转录转换技能

## 用途

将语音转录产生的口语化文本（包含填充词、语气词、口语表达、Whisper 转录错误等）转换为规范的书面中文文稿。

## 触发条件

- 用户要求将口语转录转为书面语
- 用户提到"转录文稿"、"书面文稿"、"转写"、"润色转录文本"
- 用户需要在 `out/` 目录下处理转录文件
- 用户说"写书面文稿"、"输出书面版"、"转换成书面"、"口语化转书面"
- 您识别到用户正在处理转录文本，并主动建议使用此技能进行书面化处理

## 工作流程

### 1. 定位转录文件

转录文稿位于项目 `out/作者/` 目录下的子目录中，格式为：

```
out/作者/<作者名>/<视频ID>_<视频标题>/转录文稿.txt
```

同时支持通过 `out/系列/` 和 `out/作品/` 下的软连接访问。

### 2. 运行转换脚本

```bash
cd /root/bilibili-transcript
python .agents/skills/convert-to-written/scripts/convert_to_written.py
```

脚本会自动扫描 `out/作者/*/*/转录文稿.txt`（兼容旧结构 `out/*/转录文稿.txt`），为每个文件生成对应的 `书面文稿.txt`。

### 3. 验证输出

检查 `out/*/书面文稿.txt` 是否生成成功，内容是否合理。

## 转换规则概览

脚本依次执行以下处理：

1. **Whisper 错误修正** — 修复常见语音识别错误（如"月入过万"误为"欲如过万"、"人设"误为"人色"等）
2. **去除口语填充词** — 删除"对吧"、"是不是"、"嗯"、"啊"、"我跟你说"等无实际意义的填充词
3. **口语表达书面化** — 将"比如说"→"例如"、"所以说"→"因此"、"说白了"→"简而言之"等
4. **标点规范化** — 合并重复标点、省略号规范化
5. **空白清理** — 移除多余空行和行首尾空白
6. **后处理** — 修复"读者"→"大家"等上下文敏感替换

## 注意事项

- 转录不完整的文件（≤15行）会保持原样，不做转换
- 输出文件与输入文件在同一目录，命名为 `书面文稿.txt`
- 转换是单向的，如果对结果不满意，需要手动编辑
- 该脚本仅适用于当前项目（bilibili-transcript）的转录文稿格式
