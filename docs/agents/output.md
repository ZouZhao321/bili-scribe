# 输出位置

转录完成后，结果保存在 `out/` 下。

**目录名含模型标识**：`out/{BV号}_{标题}_{模型}/`。同一视频用不同模型转录时，产物并存、互不覆盖。

```
out/
├── BV15N4y1H7vd_标题_base/
│   ├── 视频信息.txt
│   ├── 转录文稿.txt
│   └── audio.m4s
├── BV15N4y1H7vd_标题_small/     ← 同一视频、不同模型：并存
└── ...
```

- **同模型重跑**复用同一目录并覆盖 `转录文稿.txt`（任务 retry 依赖这个幂等语义）。
- 标题截断 100 字符，`/`、`\`、空格替换为 `_`。
- 下游脚本按 `re.match(r"BV[a-zA-Z0-9]+", 目录名)` 解析，模型后缀在末尾不影响解析。
