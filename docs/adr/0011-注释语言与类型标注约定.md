# ADR 0011: 注释语言与类型标注约定

## 状态

已接受（2026-10-10）

## 背景

项目对外开源，注释与文档字符串是外部贡献者理解代码的主要入口，其语言选择与完整程度直接决定外部读者的阅读成本。

## 决策

### 注释语言：英文

- 内联注释、模块与函数文档字符串统一使用英文
- identifier 与专用名词保持英文原名
- 适用对象：Python 源码、脚本与配置文件

### 文档字符串格式：Google 风格

- 段落标题使用 `Args:`、`Returns:`、`Raises:`、`Attributes:`
- 模块文档字符串置于文件顶部，说明模块职责与关键流程

### 类型标注：必须

- 所有函数与方法的参数与返回值必须带类型标注
- 无法确定具体类型的，使用 `Any`、`Optional`、`Iterator` 等显式标注
- 类属性在定义处标注

## 影响

- 正向：外部贡献者可直接阅读注释与文档字符串
- 负向：既有代码中的中文注释与缺失的类型标注与本约定不一致，改动触及这些文件时审查工具会给出提示
- 约束：注释不再承担中文说明职责，中文说明放在 `docs/`
