# ADR 0002: 三级降级转录策略

## 状态

已接受（2026-07-17）

## 背景

B 站视频的字幕可用性不可预测：有的 UP 主上传了 CC 字幕，有的有 B 站 AI 自动生成的字幕，有的完全没有字幕。需要自动选择最优字幕来源，保证用户体验。

## 决策

采用三级降级策略，按优先级从高到低依次尝试：

```
第 1 级：CC 字幕（UP 主上传）→ 秒出，质量最高
第 2 级：AI 字幕（B 站自动生成）→ 秒出，质量中等
第 3 级：Whisper 本地转录 → 较慢但最可靠
```

### 实现细节

- 判断字幕源：`subtitle_source` 字段，"CC" 表示用户上传，"AI" 表示自动生成
- 三级降级在 `get_subtitle_url()` 函数中实现
- Whisper 转录仅在 CPU 资源允许时触发（队列模式有 CPU 感知调度）

## 影响

- 正向：90% 以上的视频可以在 1 秒内返回字幕
- 正向：无字幕视频也能通过 Whisper 兜底，保证可用性
- 约束：Whisper 转录需要 CPU 资源，2 核 CPU 转录 10 分钟视频约需 6 分钟
- 约束：Whisper 模型需要下载，首次使用需联网
