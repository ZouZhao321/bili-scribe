# ADR 0001: 技术栈与包管理选型

## 状态

已接受（2026-07-17 → 2026-07-30）

## 背景

需要构建一个 B 站视频字幕提取 + Whisper 本地语音转录工具。核心需求：
1. 调用 B 站 API 提取 CC 字幕和 AI 字幕
2. 降级到本地 Whisper 语音转录
3. 支持多种输出格式（文本/时间戳/JSON/SRT）

## 决策

### 运行时语言：Python 3.10+

- **原因**：faster-whisper 仅提供 Python 绑定，Python 生态在 AI/ML 领域最成熟
- **替代方案**：Go（无成熟 Whisper 绑定），Node.js（whisper-node 质量不及 faster-whisper）

### Whisper 后端：faster-whisper（CTranslate2）

- **原因**：比 OpenAI whisper 快 4 倍，内存占用更低，支持 int8 量化
- **替代方案**：openai-whisper（慢 4 倍，内存更高），whisper.cpp（C++ 绑定，工程复杂度高）

### 包管理器：uv（2026-07-30 从 pip 迁移）

- **原因**：比 pip 快 10-100 倍，原生支持 pyproject.toml，依赖解析更可靠
- **迁移过程**：删除 requirements.txt，项目仅保留 pyproject.toml
- **替代方案**：pip（速度慢，无锁文件），poetry（生态不如 uv 活跃）

### Web 框架：FastAPI + Uvicorn

- **原因**：原生异步支持，自动生成 OpenAPI 文档，Pydantic 类型校验
- **替代方案**：Flask（同步，需额外插件），Django（太重）

### 代码质量工具：Ruff（linter + formatter）

- **原因**：比 Flake8 + Black + isort 快 100 倍，统一配置
- **配置特点**：120 行宽，Python 3.10 目标，中文项目特殊规则（允许全角字符）

## 影响

- 正向：uv 使 CI 和环境初始化速度提升显著
- 正向：Ruff 统一配置减少了代码风格争议
- 约束：Python 3.10+ 限制了部署环境的 Python 版本
- 约束：faster-whisper 的 CTranslate2 依赖需要较新的 glibc
