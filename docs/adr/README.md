# 架构决策记录 (ADR)

本目录记录 Bilibili Transcript 项目的关键架构决策。

## 格式

每个 ADR 包含：
- **标题**：决策的简短描述
- **状态**：已接受 / 已废弃 / 已替代
- **背景**：为什么需要做出这个决策
- **决策**：选择了什么方案，为什么
- **影响**：正向和负面的影响
- **相关链接**：代码位置、commit、文档

## 新增 ADR

新增 ADR 时，请遵循以下规则：
1. 编号递增（如 0011）
2. 文件名格式：`NNNN-简短描述.md`
3. 更新此索引文件，按日期排序
4. 如果替代了旧的 ADR，在旧 ADR 状态中标注"已替代"并链接到新 ADR
