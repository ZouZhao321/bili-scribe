# ADR 0007: 输出目录结构与文库管理

## 状态

已接受（2026-07-31 → 2026-08-05）

## 背景

随着转录的视频数量增加（27+ 个网文写作教学视频），输出文件管理变得混乱。需要：
1. 每个视频有独立目录，文件命名稳定
2. 支持按作者、系列、作品等多维度聚合
3. 区分"原始下载"和"整理后"两层

## 决策

### 输出命名规范

- 目录名：`out/BV号_标题/`
- 文件名：`audio.m4s`、`视频链接.txt`、`字幕.srt`（统一命名，不包含 BV 号）
- **不包含 task_id**：确保同一视频多次转录输出位置相同
- 标题截断从 20 字增加到 100 字，避免过长文件名

### 二层结构：下载目录 + 文库

```
out/                         ← 下载目录（新转录的原始输出，平铺）
├── BV15N4y1H7vd_标题/
│   ├── 视频链接.txt
│   ├── 字幕.srt
│   └── audio.m4s
└── ...

library/                     ← 整理后的文库（按作者/系列/作品聚合）
├── 作者/
│   ├── 徐善良/
│   ├── 通用教程/
│   └── ...
├── 系列/                    ← 软连接（按主题聚合）
├── 作品/                    ← 软连接（按被拆解的小说名聚合）
└── 大纲                     ← 保留（手动编辑的摘要文件）
```

### 为什么是软连接？

- 一个视频可能属于多个系列（如"网文大纲"和"拆书"）
- 软连接实现多维度聚合，不复制文件
- 物理存储只有一份，减少磁盘占用

### 迁移脚本

- `scripts/migrate_out_structure.py`：将旧目录结构迁移到新结构
- 处理重复目录（如 `BV1jBgb6KEAg` 合并保留完整版）
- 处理特殊目录（如 `大纲/` 中的 12 个视频迁入通用教程）

## 影响

- 正向：文件命名稳定，不因 task_id 变化
- 正向：多维度聚合方便查找
- 正向：下载目录保持简单，文库按需整理
- 约束：需要运行迁移脚本转换旧目录
- 约束：软连接在 git 中需要特殊处理
