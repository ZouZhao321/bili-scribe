# ADR 0005: 单工作者与任务队列并发模型

## 状态

已接受（2026-07-30）

## 背景

Whisper 模型加载到内存后约 500MB-3GB（取决于模型大小），且 CTranslate2 后端在多进程场景下可能冲突。需要设计并发模型。

## 决策

### 模型：单进程 + 内存任务队列

- **单工作者**：后台线程运行，从队列取任务依次执行
- **原因**：Whisper 模型大（GB 级），多实例加载会耗尽内存；CTranslate2 多进程存在竞态
- **替代方案**：Celery + Redis（太重，小项目不适用），多进程 Worker（内存爆炸）

### 线程安全

- 使用 `threading.Lock` 保护队列操作
- 任务状态机：`pending → processing → completed / failed`
- 单工作者模式避免了锁竞争

### 优雅退出

- Worker 支持 `stop()` 信号
- 当前任务完成后才退出，不中断正在进行的转录

## 影响

- 正向：设计简单，无外部依赖（不需要 Redis/RabbitMQ）
- 正向：内存占用可控，一次只加载一个模型
- 约束：一次只能转录一个视频，并行数为 1
- 约束：如果有长时间任务，后续任务需要等待
