# ADR 0010: 转录结果自动提交到 Git 分支

## 状态

已接受（2026-08-05）

## 背景

转录完成后，文稿和音频文件散落在 `out/` 目录中。需要一种机制来：
1. 记录每次转录的时间点和结果
2. 方便回溯和版本管理
3. 自动同步到远程仓库备份

## 决策

### 流程

转录完成后自动执行：
1. 创建临时分支：`transcribe/YYYYMMDD_HHMMSS_BVxxx`
2. 将 `out/BVxxx_标题/` 目录中所有文件添加到暂存区
3. 提交，提交信息格式：`feat(transcribe): BVxxx 视频标题`
4. 推送到远程仓库

### 实现

在 `runner.py` 中新增 `git_commit_and_push()` 函数：
- 转录成功后立即执行
- 使用 subprocess 调用 `git checkout -b`、`git add`、`git commit`、`git push`
- 不切换 main 分支，保证 main 分支只包含代码变更

### 不包含的提交内容

- 仅提交 `out/` 目录下的转录结果
- 不提交 `library/`（整理后的文库需手动管理）
- 不提交临时文件或中间产物

## 影响

- 正向：每次转录都有 git 记录，可回溯
- 正向：远程仓库自动备份，防止数据丢失
- 正向：main 分支保持干净，只包含代码
- 约束：大量转录文件会增加 git 仓库大小
- 约束：音频文件（.m4s）可能较大，不适合长期在 git 中保留
