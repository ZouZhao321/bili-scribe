# Whisper 内存管理要点

## 模型加载机制

faster-whisper 基于 CTranslate2，使用 **mmap（内存映射文件）** 加载模型。

- 模型文件不是一次性全部读入物理内存（RSS）
- 而是映射到虚拟地址空间，按需按页加载到物理内存
- 物理内存不够时，OS 自动将不常用的权重页换出到 Swap

## 内存需求

| 模型 | 磁盘大小 | 实际物理内存需求 |
| :--- | :---: | :---: |
| tiny | 75MB | ~75MB |
| small | 464MB | ~464MB |
| medium | 1.5GB | ~1.5GB |
| large-v3 | 2.9GB | ~2.9GB |

## 卡死原因

系统配置 3.6GB RAM，**卡死的根本原因不是模型太大，而是 Swap 太小**。

- 默认 Swap 1.9GB → medium/large-v3 卡死
- 加大 Swap 到 4GB → large-v3 稳定运行

## 注意事项

- 模型权重是内存占用的绝对大头，音频特征占比可忽略
- 音频全部加载到内存，不是流式读取
- 5 分钟音频的特征仅 ~5MB
- 使用 small 模型时需确保可用内存 ≥ 2GB
